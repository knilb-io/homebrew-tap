# knilb-io/homebrew-tap

Homebrew tap for the [knilb](https://github.com/knilb-io/knilb-dist) command-line interface.

## Install

```bash
brew install knilb-io/tap/knilb
```

Or in two steps:

```bash
brew tap knilb-io/tap
brew install knilb
```

## Upgrade

```bash
brew update && brew upgrade knilb
```

## Uninstall

```bash
brew uninstall knilb
brew untap knilb-io/tap
```

## Source

This repository contains only the Homebrew formula. Binary releases are hosted at [knilb-io/knilb-dist](https://github.com/knilb-io/knilb-dist).
